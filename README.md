# The Salvage Yard Antiques - React Application

A warm, rustic antique and architectural salvage React JS website built for The Salvage Yard Antiques in Grand Ledge, MI.

## Business Details
- **Address:** 208 S Bridge St, Grand Ledge, MI 48837
- **Phone:** (517) 622-2001
- **Hours:** Tuesday - Sunday: 10:00 AM - 5:00 PM | Monday: Closed

## Features
- Filterable & Searchable Vintage Inventory Gallery (Furniture, Architectural Salvage, Vintage Signs, Collectibles, Lighting, Glassware)
- Item Inquiry & Appraisal / Consignment Form Modal
- High-Resolution Antique Photography & Showroom Tour
- Featured Rare Vintage Finds of the Month
- Vendor Space Dealer Inquiry Section
- Map, Address & Hours Information for Downtown Grand Ledge

## Quick Start
```bash
npm install
npm run dev
```
